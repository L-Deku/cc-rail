# 模板铺量定额材料稳定排序 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让模板铺量同一工程量的预览和写入稳定遵守“定额 → 材料 → 辅助代码”，并使现有圈梁模板无需重建即可正确显示。

**Architecture:** 在 `TemplateFillNameMatch.cs` 增加唯一的目标类别排序函数，模板组件组和对应框组件组共同使用。模板组件组在类别和 `OrderInItem` 相同时，以模板原始行下标作为最终稳定比较项，不修改模板或对应框数据结构。

**Tech Stack:** C# 5、.NET Framework 4.6、WinForms、Windows PowerShell 5、反射回归测试。

## Global Constraints

- 排序固定为普通定额、五位及以上纯数字材料（允许 `*系数`）、辅助代码。
- 同类别先按 `OrderInItem`，仍相同则按模板原始行位置。
- 不重新生成、重写或迁移现有模板和 `mapping-boxes.jsonl`。
- 不改变工程量名称匹配、章节判断、自动匹配得分、勾选规则、数量换算和表头禁用排序行为。
- 只构建和发布 `RecoExpandPanel.dll`；不得重建或复制 `RecoQuotaData`、其他插件 DLL 或同事数据。
- 只部署到 `D:\AI文件\自动预算` 工作区内的运行目录；工作区外目录不在本计划授权范围内。

- [ ] **Step 3: 实现统一类别排序和原始行兜底**

在 `TemplateFillNameMatch.cs` 中用以下函数替换 `PseudoQuotaRank`，并把现有调用改成 `TemplateTargetRank`：

```csharp
// 模板/对应框组内顺序：真定额、数字材料、费用或辅助类伪代码。
// 数字材料允许带 *系数 后缀；五位以下纯数字不在这里判为材料。
private static int TemplateTargetRank(string code)
{
    string c = (code ?? "").Trim().ToUpperInvariant();
    int star = c.IndexOf('*');
    if (star > 0) c = c.Substring(0, star);
    switch (c)
    {
        case "SF": case "SH": case "SQ": case "ZLF": case "LF":
        case "YF": case "TLF": case "GF": case "JF": case "XGT1":
            return 2;
    }
    if (c.Length >= 5 && c.All(Char.IsDigit)) return 1;
    return 0;
}
```

对应框目标排序改为：

```csharp
.OrderBy(target => TemplateTargetRank(target.QuotaCode))
.ThenBy(target => target.QuotaCode, StringComparer.OrdinalIgnoreCase)
```

模板组件比较器改为：

```csharp
indexes.Sort(delegate(int a, int b)
{
    int ra = TemplateTargetRank(template.Rows[a].QuotaCode);
    int rb = TemplateTargetRank(template.Rows[b].QuotaCode);
    if (ra != rb) return ra.CompareTo(rb);
    int order = template.Rows[a].OrderInItem.CompareTo(template.Rows[b].OrderInItem);
    if (order != 0) return order;
    return a.CompareTo(b);
});
```
