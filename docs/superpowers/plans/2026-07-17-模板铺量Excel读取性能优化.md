# 模板铺量 Excel 读取性能优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变模板铺量业务结果的前提下，消除大型 `.xlsx` 的重复整簿解析和窗口首次打开时的重复工作簿枚举。

**Architecture:** 保留现有 `ExcelSyncReadContext` 和两套保存文件读取器，只把 `.xlsx/.xlsm` 的定点 XML 读取移到 NPOI 之前，并保留 NPOI 回退；按名称生成模板先收集全批地址，再创建一个共享上下文。窗口层仅抑制模板列表初始化触发的重复刷新，用户后续切换模板仍走原事件链。

**Tech Stack:** C# 5、.NET Framework WinForms、Windows PowerShell 5、NPOI、System.IO.Compression、现有反射回归脚本、`csc.exe` 编译链。

## Global Constraints

- 不修改匹配规则、表达式、单位换算、模板 JSON、原生写入、数据库连接和定时同步线程模型。
- `.xls` 继续只使用 NPOI；`.xlsx/.xlsm` 定点读取失败必须回退 NPOI。
- 不增加跨操作工作簿缓存，不持有新的 COM 对象。
- 当前 14 个 `tools/RecoExpandPanel/*.cs` 必须编译到工作区 `RecoQuotaRecommend/obj/expand-source-test` 后再运行反射测试。
- 不还原或暂存用户现有的 `ServerSetting.xml`、工程数量表删除项和无关未跟踪文档。
- `tools/RecoExpandPanel/ExcelLinkFeature.cs:190-242` 已有并行的自动匹配保存计数改动；本任务只修改该文件约 5404-5625 行的读取上下文，并按 hunk 暂存，禁止把前述并行改动带入提交。
- 软件进程未关闭时不得覆盖运行目录 DLL；工作区外部署必须另获明确同意。

- [ ] **Step 1: 增加批量上下文创建方法**

在 `BuildNameFillTemplateFromBindings` 前加入：

```csharp
private static ExcelSyncReadContext CreateNameFillReadContext(
    FillTemplate template,
    Dictionary<string, HashSet<int>> hiddenCache,
    Dictionary<string, List<ExcelMergedRegion>> mergedCache)
{
    List<ExcelQuotaLink> readLinks = new List<ExcelQuotaLink>();
    if (template == null || template.Rows == null) return new ExcelSyncReadContext(readLinks);

    foreach (FillTemplateRow row in template.Rows)
    {
        if (row == null) continue;
        string workbook = GetTemplateRowWorkbookPath(template, row);
        if (String.IsNullOrWhiteSpace(workbook) || String.IsNullOrWhiteSpace(row.SourceSheet) ||
            String.IsNullOrWhiteSpace(row.SourceExpr)) continue;

        List<string> cells = ExtractCellAddressesFromExpression(row.SourceExpr);
        if (cells.Count <= 1)
        {
            AddQuantityNameReadLinks(readLinks, workbook, row.SourceSheet, row.SourceExpr, hiddenCache, mergedCache);
        }
        else
        {
            foreach (string cell in cells)
                AddQuantityNameReadLinks(readLinks, workbook, row.SourceSheet, cell, hiddenCache, mergedCache);
        }
    }
    return new ExcelSyncReadContext(readLinks);
}
```
