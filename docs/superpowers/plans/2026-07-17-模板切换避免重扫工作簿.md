# 模板切换避免重扫工作簿 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让模板铺量切换模板时只切换已保存关系，不再枚举全部 Excel/WPS 或整簿读取大型 `.xlsx` 的 sheet 列表。

**Architecture:** 解除模板下拉框与 `ReloadTargetWorkbooks()` 的事件耦合，保留窗口初始化和目标 Excel 下拉展开时的实时刷新。新增模板铺量专用 sheet 名称读取方法，`.xlsx/.xlsm` 复用现有 ZIP/XML 读取器并保留 NPOI 回退，`.xls` 保持 NPOI。

**Tech Stack:** C# 5、.NET Framework WinForms、Windows PowerShell 5、NPOI、System.IO.Compression、现有反射回归脚本、`csc.exe` 编译链。

## Global Constraints

- 不修改模板 JSON、匹配、预览、单位换算、右键绑定和写入逻辑。
- 切换模板后保持当前目标 Excel 和目标 sheet，不自动改变目标文件。
- 目标 Excel 下拉展开时仍执行 `ReloadTargetWorkbooks()`，保证打开/关闭的 Excel/WPS 能被刷新。
- `.xlsx/.xlsm` 快速 sheet 读取失败必须回退 NPOI；`.xls` 只使用 NPOI。
- 当前 14 个 `tools/RecoExpandPanel/*.cs` 必须编译到工作区 `obj` 后再运行反射测试。
- 不暂存或还原用户现有 `ServerSetting.xml` 与工程数量表删除项。
- `ReJJGSNet2024.exe` 当前运行时不得覆盖任何运行目录 DLL；部署前必须确认软件已关闭。

- [ ] **Step 1: 新增格式分流方法**

在 `GetSelectedTargetWorkbookPath` 前加入：

```csharp
private static List<string> GetTemplateFillSheetNames(string path, out string error)
{
    error = null;
    string extension = Path.GetExtension(path ?? "");
    bool directXlsxCandidate = String.Equals(extension, ".xlsx", StringComparison.OrdinalIgnoreCase) ||
        String.Equals(extension, ".xlsm", StringComparison.OrdinalIgnoreCase);
    if (directXlsxCandidate)
    {
        List<string> directNames = GetXlsxSheetNames(path, out error).ToList();
        if (directNames.Count > 0) return directNames;
    }

    return GetSheetNamesByNpoi(path, out error).ToList();
}
```
