# 绑定Excel直达自动匹配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让定额输入表右键“绑定Excel工程量”直接打开现有自动匹配窗口，删除旧手动绑定面板和 `Ctrl+E` 入口，同时完整保留自动匹配窗口内的手动匹配及其它 Excel 功能。

**Architecture:** 只调整 `FormPanel` 的入口层：把旧面板内部的自动匹配窗口打开和结果保存逻辑上移为静态方法，右键直接调用它。`AutoMatchDialog`、自动匹配算法、Excel 快照、单位换算、存储结构和其它面板不做行为修改。

**Tech Stack:** C# 5、WinForms、Windows PowerShell 5、.NET Framework `csc.exe`

## Global Constraints

- 只修改当前工作区，不向工作区外部署或复制文件。
- 自动匹配窗口内“手动匹配”、单个绑定、全部绑定必须保留。
- `Ctrl+E` 取消；`Ctrl+Shift+E`、Excel 快速绑定、Excel 联动面板和模板铺量保持不变。
- 只删除 `ExcelSmartBindPanel` 专属代码，不删除仍被其它流程调用的 `PromptExcelCell`、`QuickBindPanel` 或绑定辅助方法。
- 仅更新 `RecoExpandPanel.dll` 对应发布文件，不重建或复制 `RecoQuotaData`、其它插件 DLL 或同事数据。
- 修改使用补丁方式，不格式化或重构无关代码。

```csharp
private static void ShowAutoMatchDialog(Form mainForm)
{
    try
    {
        EnsureExcelLinkRuntime(mainForm);
        SqlConnection conn = GetProjectConnection(mainForm);
        if (conn == null)
        {
            MessageBox.Show(mainForm, "没有找到当前项目数据库连接。", "Excel联动", MessageBoxButtons.OK, MessageBoxIcon.Warning);
            return;
        }

        AutoMatchDialog dialog = new AutoMatchDialog(mainForm, conn);
        dialog.Accepted += delegate(List<AiMatchPreviewItem> accepted)
        {
            SaveAutoMatchPreviewAccepted(mainForm, conn, accepted);
        };
        dialog.Show(mainForm);
    }
    catch (Exception ex)
    {
        Log("Open auto Excel match failed: " + ex);
        MessageBox.Show(mainForm, "打开自动匹配Excel工程量失败：" + ex.Message, "Excel联动", MessageBoxButtons.OK, MessageBoxIcon.Error);
    }
}

private static void SaveAutoMatchPreviewAccepted(Form mainForm, SqlConnection conn, List<AiMatchPreviewItem> accepted)
{
    try
    {
        if (accepted == null || accepted.Count == 0)
        {
            return;
        }

        ExcelLinkStore store = LoadStore(conn);
        foreach (AiMatchPreviewItem item in accepted)
        {
            if (item == null || item.Link == null)
            {
                continue;
            }

            item.Link.ExcelPath = item.WorkbookPath ?? "";
            item.Link.WorksheetName = item.WorksheetName ?? "";
            item.Link.CellAddress = item.CellAddress;
            item.Link.Expression = item.Expression;
            item.Link.LastSyncValue = item.DisplayValue ?? "";
            item.Link.QuantityName = item.QuantityName ?? "";
            item.Link.LastStatus = "自动匹配绑定，等待同步";
            item.Link.UpdatedAt = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss", CultureInfo.InvariantCulture);
            store.Upsert(item.Link);
        }

        SaveStore(conn, store);
        EnsureExcelLinkRuntime(mainForm);
        if (ExcelLinkRuntimes.ContainsKey(mainForm))
        {
            ExcelLinkRuntimes[mainForm].Reload();
        }

        RefreshExcelLinkPanel(mainForm);
    }
    catch (Exception ex)
    {
        Log("Save auto Excel match preview failed: " + ex);
        MessageBox.Show(mainForm, "保存自动匹配绑定失败：" + ex.Message, "Excel联动", MessageBoxButtons.OK, MessageBoxIcon.Error);
    }
}
```
