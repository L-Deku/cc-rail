# 禁用绑定与铺量表头排序 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 禁止“自动匹配 Excel 工程量”和“模板铺量”两个窗口通过点击表头改变行顺序，同时保持所有既有业务流程不变。

**Architecture:** 在两个 WinForms `DataGridView` 完成列创建后，逐列设置 `DataGridViewColumnSortMode.NotSortable`。修改局限于列初始化，不增加点击事件、不改数据源、不重排任何业务集合；使用针对性源码回归检查和干净源码快照构建验证交付物。

**Tech Stack:** C# 5、.NET Framework WinForms、Windows PowerShell 5、现有 `csc.exe` 编译链。

## Global Constraints

- 两个窗口的所有列均禁止点击表头排序，并保持软件生成的原始业务顺序。
- 不修改自动匹配、手动匹配、勾选、单个绑定、全部绑定、表达式、数量换算、模板铺量写入或数据保存逻辑。
- 不修改其他窗口的表格，也不增加新的配置项或公共抽象。
- 保留当前工作树中本任务范围外的所有未提交修改，不还原、不提交、不混入构建 DLL。
- 构建发布 DLL 必须来自当前已确认提交的干净源码快照，只包含本任务改动。
- 未经用户明确许可，不向 `D:\AI文件\自动预算` 工作区外的运行目录写入任何文件。
- 目标软件进程运行时不得覆盖运行目录 DLL；不主动关闭用户的软件进程。
- 只同步 `RecoExpandPanel.dll` 到当前工作区运行目录和既有综合扩展发布位置，不复制或重建 `RecoQuotaData`。
