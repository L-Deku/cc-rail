# 自动绑定 Excel 保持窗口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让“自动匹配 Excel 工程量”窗口在点击“全部绑定”后保持打开，并在左下角显示本次实际保存成功的绑定数量。

**Architecture:** 保留现有预览收集和绑定存储链路，只把 `Accepted` 回调从无返回值动作改为返回成功数量的函数。存储入口在全部保存、运行时重载和联动面板刷新成功后返回有效保存条数；窗口据此更新现有状态栏，并删除“全部绑定”路径中的自动关闭代码。

**Tech Stack:** C# 5、.NET Framework WinForms、Windows PowerShell 回归脚本、`csc.exe`

## Global Constraints

- 保留底部“取消”按钮和右上角叉号的关闭能力。
- 不改变可绑定项目筛选、Excel 绑定数据结构、数据库结构或同步逻辑。
- 不清空勾选、不重新匹配、不刷新整个预览表。
- 仅修改 `tools/RecoExpandPanel/` 范围内与本需求直接相关的源码和测试。
- 未经用户另行明确同意，不向当前工作区以外的运行目录部署或复制 DLL。

- [ ] **Step 1: 让存储入口返回成功数量**

把窗口订阅和保存方法改为以下结构：

```csharp
dialog.Accepted += delegate(List<AiMatchPreviewItem> accepted)
{
    return SaveAutoMatchPreviewAccepted(mainForm, conn, accepted);
};
```

```csharp
private static int SaveAutoMatchPreviewAccepted(Form mainForm, SqlConnection conn, List<AiMatchPreviewItem> accepted)
{
    try
    {
        if (accepted == null || accepted.Count == 0)
        {
            return 0;
        }

        int saved = 0;
        ExcelLinkStore store = LoadStore(conn);
        foreach (AiMatchPreviewItem item in accepted)
        {
            if (item == null || item.Link == null)
            {
                continue;
            }

            item.Link.ExcelPath = item.WorkbookPath ?? "";
            item.Link.WorksheetName = item.WorksheetName ?? "";
            item.Link.CellAddress = item.CellAddress;
            item.Link.Expression = item.Expression;
            item.Link.LastSyncValue = item.DisplayValue ?? "";
            item.Link.QuantityName = item.QuantityName ?? "";
            item.Link.LastStatus = "\u81ea\u52a8\u5339\u914d\u7ed1\u5b9a\uff0c\u7b49\u5f85\u540c\u6b65";
            item.Link.UpdatedAt = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss", CultureInfo.InvariantCulture);
            store.Upsert(item.Link);
            saved++;
        }

        SaveStore(conn, store);
        EnsureExcelLinkRuntime(mainForm);
        if (ExcelLinkRuntimes.ContainsKey(mainForm))
        {
            ExcelLinkRuntimes[mainForm].Reload();
        }

        RefreshExcelLinkPanel(mainForm);
        return saved;
    }
    catch (Exception ex)
    {
        Log("Save auto Excel match preview failed: " + ex);
        MessageBox.Show(mainForm, "\u4fdd\u5b58\u81ea\u52a8\u5339\u914d\u7ed1\u5b9a\u5931\u8d25\uff1a" + ex.Message, "Excel\u8054\u52a8", MessageBoxButtons.OK, MessageBoxIcon.Error);
        return 0;
    }
}
```
