**Goal:** 把"接受推荐"接回学习库形成完整闭环,在有最低正反馈门槛的前提下放开被过严判定与权重封顶锁死的

并把学习库查询代价按需收敛。最终目的是让同一个工程量名不必反复人工确认。

判定侧 `CanAutoSelectSmartMapEntry` 分层判定 + 最低正反馈门槛 + 真正使用三个计数;
权重去上限(写入端 / 本机 jsonl 端 / 重算端三处同步,并保护共享 SQL weight 不被本机覆盖);
读取侧半连接下推 + 合并重复查询;离线加共享熔断(覆盖 5 个入口)。
快照缓存本批**不做**。最后在维护窗口做一次全量重算收敛归一化。

**Tech Stack:** C# 5 / WinForms(`tools/RecoExpandPanel/`)+ PowerShell(`tools/RecoLearning/`)+
SQL Server(`192.168.2.213/RecoLearning`)。聚合表可随时由 `BindingLog` 重算。

  ```csharp
  private static bool CanAutoSelectSmartMapEntry(List<SmartMapCandidateScore> scores)
  {
      if (scores == null || scores.Count == 0) return false;
      SmartMapCandidateScore top = scores[0];
      if (!top.CurrentTargetsValid || !top.HasEntry || !top.HasCurrentContext) return false;
      if (!top.HasCurrentMethodMapping && !IsSingleQuotaTargetBox(top.Entry)) return false;
      if (scores.Count == 1) return true;

      SmartMapCandidateScore second = scores[1];
      if (!second.CurrentTargetsValid) return true;
      if (top.HasCurrentMethodMapping && !second.HasCurrentMethodMapping &&
          HasMinimumPositiveEvidence(top)) return true;
      if (top.HasCurrentContext && !second.HasCurrentContext &&
          HasMinimumPositiveEvidence(top)) return true;
      int topWeight = top.Entry == null ? 0 : top.Entry.Weight;
      int secondWeight = second.Entry == null ? 0 : second.Entry.Weight;
      if (topWeight - secondWeight >= 20) return true;
      // 小样本：净证据分呈倍数领先也可静默决定。
      return topWeight >= 2 * secondWeight && topWeight - secondWeight >= 10;
  }
  ```
- [ ] **空办法单目标特例**:`IsSingleQuotaTargetBox(entry)` = 该组件框只有一个
      `target_kind='quota'` 的目标。仅此情形允许"唯一空办法候选 + 当前办法唯一条目证据"
      自动采纳(此时 `SignatureEntryMap` 的目标级证据 ≡ 组件框级证据)。
      **多目标框在 `!HasCurrentMethodMapping` 时一律返回 false。**
- [ ] 文档与注释统一用"净证据权重比较",**不要**写"2 次对 1 次"
      (`corrected` 20 分、`rejected` −10 分,按次数描述会误导)。
- [ ] 行为测试:
  - top 有当前办法但只有 1 次 accepted、second 是空办法高权重 → **不自动采纳**;
  - top 累计 2 次 accepted → 自动采纳;
  - top 1 次 corrected → 自动采纳;
  - 同权重且都有当前办法证据 → 不自动采纳;
  - top 被 rejected 压到低于 second → 不自动采纳;
  - **单 quota 目标**框 + 唯一空办法候选 + 当前办法唯一条目证据 → 自动采纳;
  - **多目标**框在相同条件下 → 仍需人工确认。
