# 插件稳定性与启动性能三批优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变业务匹配规则的前提下，完成映射文件安全写入、日志轮转、大索引共享和后台重试降频。

**Architecture:** 保持现有 WinForms/C# 入口不变，在各自程序集内加入最小的文件安全与缓存机制。缓存以绝对数据目录、运行办法、文件时间和长度作为失效指纹，所有用户写入仍走原有方法。

**Tech Stack:** C# 5、.NET Framework WinForms、PowerShell 5 回归脚本、JSONL 本地文件。
