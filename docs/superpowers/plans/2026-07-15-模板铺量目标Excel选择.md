# 模板铺量目标 Excel 选择 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让模板铺量自动列出当前打开且已保存的 Excel/WPS 工作簿，并让列锚点和名字驱动预览严格从用户选定的目标工作簿取数。

**Architecture:** 在现有 `FormPanel` partial class 内增加轻量工作簿描述对象和一次性 COM 枚举方法，模板铺量面板用“目标 Excel -> 目标 sheet”两级联动选择。预览引擎显式接收目标工作簿路径，模板源工作簿仅作为兼容候选，不再承担隐式目标路径。

**Tech Stack:** C# 5、WinForms、Excel/WPS COM late binding、NPOI、Windows PowerShell 5 反射回归、现有 `RecoQuotaRecommend/build.ps1` 构建链路。

## Global Constraints

- 不修改模板 JSON 字段、Excel 绑定数据、定额匹配规则、目标单元写入事务和学习反馈规则。
- 只把已保存且路径存在的工作簿作为打开工作簿候选；模板源文件存在时可作为明确的兼容项。
- 目标工作簿按完整路径隔离，同名 sheet 不得跨工作簿回退。
- 工作簿枚举只在初始化、切换模板或展开目标 Excel 下拉时执行，不进入 COM 轮询热路径。
- 保持 C# 5 兼容，不引入新框架或 Office Interop 编译依赖。
- 数量为零的工程量继续直接丢弃。
- 只修改本需求相关文件，保留用户已有 `ServerSetting.xml` 和工程数量表工作区状态。
- 构建部署后同步 `release/同事插件分层发布/` 的两个 `RecoExpandPanel.dll` 和 SHA256 清单，不复制 `RecoQuotaData` 或其他插件。

private static List<FillPreviewItem> BuildPreview_ColumnAnchor(
