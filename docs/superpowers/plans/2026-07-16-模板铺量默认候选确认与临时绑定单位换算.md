# 模板铺量默认候选确认与临时绑定单位换算 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让同名多来源的当前默认候选可直接勾选确认，并让右键临时绑定按目标工程量单位与真实定额单位生成正确数量后缀。

**Architecture:** 候选生成和下拉切换保持不变，只新增一个“确认当前候选组”入口供勾选事件复用。右键临时绑定通过一个小型单位解析函数读取界面行的三个既有字段名，并在缺失时按定额序号从当前项目精确补取，然后继续调用现有 `BuildNameDrivenQtyText`。

**Tech Stack:** C# 5、.NET Framework 4.6、WinForms、SQL Server 项目连接、Windows PowerShell 5、反射回归测试。

## Global Constraints

- 同名多来源候选、默认候选顺序和定额编号下拉不得改变。
- 勾选默认候选必须确认当前显示的完整组件组，不能只确认组员行。
- `1400 m` 绑定到 `hm` 定额时必须生成 `1400/100`。
- 不从工程量名称猜测单位；界面和项目数据都无单位时保持现有原量行为。
- 不改变名字匹配、组合表达式取数、模板回写、组件排序、自动匹配或最终写入流程。
- 保持 C# 5 兼容，不修改 `RecoQuotaData`、模板 JSON、对应框数据或业务数据库内容。
- 只构建和发布 `RecoExpandPanel.dll`；只部署到 `D:\AI文件\自动预算` 工作区内运行目录。

```csharp
internal static bool ConfirmCurrentExactNameGroup(List<FillPreviewItem> all, int targetRow)
{
    FillPreviewItem leader = (all ?? new List<FillPreviewItem>())
        .Where(item => item != null && item.IsNameDriven && item.TargetRow == targetRow)
        .OrderBy(item => item.GroupOrder)
        .FirstOrDefault();
    if (leader == null) return false;
    if (leader.NameQuotaCandidates != null && leader.NameQuotaCandidates.Count > 1)
    {
        if (String.IsNullOrWhiteSpace(leader.SelectedNameQuotaCandidateKey)) return false;
        return ApplyExactNameCandidate(all, targetRow, leader.SelectedNameQuotaCandidateKey);
    }
    return ConfirmSingleExactNameGroup(all, targetRow);
}
```

```csharp
private static string ResolveTemplateFillQuotaUnit(SqlConnection conn, DataGridViewRow row, long quotaSequence)
{
    string unit = GetRowValue(row, "单位", "定额单位", "计量单位").Trim();
    if (!String.IsNullOrWhiteSpace(unit)) return unit;
    if (conn == null || quotaSequence <= 0) return "";

    try
    {
        EnsureOpen(conn);
        using (SqlCommand cmd = conn.CreateCommand())
        {
            cmd.CommandText = "select top 1 单位 from 定额输入 where 定额序号=@seq";
            cmd.Parameters.AddWithValue("@seq", quotaSequence);
            object value = cmd.ExecuteScalar();
            return value == null || value == DBNull.Value ? "" : Convert.ToString(value).Trim();
        }
    }
    catch (Exception ex)
    {
        Log("ResolveTemplateFillQuotaUnit failed: " + ex.Message);
        return "";
    }
}
```
