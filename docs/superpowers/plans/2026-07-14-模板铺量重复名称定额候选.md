# 模板铺量重复名称定额候选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 名字驱动预览遇到重复工程量名称时不再留空；唯一绑定整组复用，多个绑定以完整组件组下拉选择。

**Architecture:** 在运行时 `FillPreviewItem` 上保存精确同名确认状态和候选绑定组，不改变模板 JSON。预览继续按源 Excel 锚点形成组件组；表格下拉只切换当前 `TargetRow` 的完整组，并复用现有原子替换和完整写入反馈守卫。

**Tech Stack:** C# 5、WinForms `DataGridView`、Windows PowerShell 5 反射测试、现有 `RecoExpandPanel.dll` 构建脚本

## Global Constraints

- 只修改 `tools/RecoExpandPanel/` 的名字驱动预览、表格交互和测试。
- 同一源工程量锚点的多条定额是不可拆分的组件组；候选按组展示和替换。
- 未确认的红色组默认不勾选、不得写入或学习；确认后仍须整组写入成功才反馈。
- 数量为零的工程量继续直接丢弃。
- 不修改、暂存或还原用户现有 `ServerSetting.xml` 和工程数量表改动。
- 未经再次明确同意，不向当前工作区外复制 DLL、配置、数据或脚本。

internal static string GetExactNameResolutionMode(int targetCount, int groupCount)

    if (groupCount > 1) return "choice";

    if (groupCount == 1) return "single";
    return "";
}

- [ ] **Step 3: 实现候选标签和候选组**

```csharp
internal static string BuildTemplateCandidateLabel(FillTemplate template, TemplateNameGroup group)
{
    List<FillTemplateRow> rows = OrderedTemplateGroupIndexes(template, group)
        .Select(index => template.Rows[index]).ToList();
    if (rows.Count == 1) return (rows[0].QuotaCode ?? "") + "  " + (rows[0].SourceName ?? "");
    return String.Join(" + ", rows.Select(row => row.QuotaCode ?? "").ToArray()) +
        "（组件" + rows.Count.ToString(CultureInfo.InvariantCulture) + "条）";
}
```

`BuildNameQuotaCandidates` 按模板稳定顺序为每个源锚点建立一个候选；标签重复时追加首行 `SourceExpr`，`Key` 使用 `SourceAnchor`，`Items` 使用无副作用的完整组预览。

- [ ] **Step 4: 替换精确同名留空分支**

```csharp
string mode = GetExactNameResolutionMode(targetNameCount, exactGroups == null ? 0 : exactGroups.Count);
if (mode.Length > 0)
{
    List<FillPreviewItem> active = BuildTemplatePreviewGroup(
        template, exactGroups[0], tr, targetRows, targetNorms, trIdx, mergedIntoByTargetIdx);
    bool needsReview = mode == "reuse" || mode == "choice";
    foreach (FillPreviewItem member in active)
    {
        member.Selected = !needsReview;
        member.NeedExactNameConfirmation = needsReview;
    }
    if (needsReview)
    {
        active[0].Status = mode == "choice"
            ? "模板存在同名多来源，已带出候选，需下拉确认"
            : "目标表存在重复工程量名称，已带出唯一绑定，需确认";
    }
    if (mode == "choice")
    {
        active[0].NameQuotaCandidates = BuildNameQuotaCandidates(
            template, exactGroups, tr, targetRows, targetNorms, trIdx);
        active[0].SelectedNameQuotaCandidateKey = exactGroups[0].SourceAnchor;
    }
    if (!needsReview) { usedGroups.Add(exactGroups[0]); lastMatched = active[0]; }
    items.AddRange(active);
    continue;
}
```

重复目标的唯一绑定不加入 `usedGroups`，所以每个同名目标都能复用；没有精确候选时仍走原模糊匹配。
