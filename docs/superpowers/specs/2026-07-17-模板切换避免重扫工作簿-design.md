# 模板切换避免重扫工作簿设计

## 背景

模板 JSON 已保存定额对应关系、源工作簿路径、源 sheet 和源表达式。切换模板本身只需要更换当前模板名；当前实现却把 `cmbTemplate.SelectedIndexChanged` 绑定到 `ReloadTargetWorkbooks()`，因此每次切换都会重新枚举所有已打开的 Excel/WPS，并读取当前模板源工作簿的 sheet 列表。

当前“路基”模板源文件约 4.6 MB、17 个 sheet。`GetSheetNamesByNpoi` 实测需要约 4.8 秒，而其他 12–39 KB 模板源文件只需约 17–122 毫秒。全部操作都在 UI 线程执行，表现为切换模板、窗口按钮和右键同时卡顿。

## 目标

- 切换模板时只切换已生成的模板关系，不重新枚举 Excel/WPS。
- 目标 Excel 下拉框展开时继续实时刷新已打开的工作簿，保留现有发现能力。
- `.xlsx/.xlsm` 的 sheet 列表优先使用现有 ZIP/XML 快速读取器，失败时回退 NPOI。
- `.xls` 继续使用 NPOI。
- 不改变模板 JSON、匹配、预览、单位换算、右键绑定和写入逻辑。

## 方案比较

### 方案 A：解除模板切换与工作簿刷新耦合，并复用快速 sheet 读取（采用）

- 移除模板下拉框 `SelectedIndexChanged -> ReloadTargetWorkbooks` 事件。
- 保留窗口首次打开和目标 Excel 下拉展开时的 `ReloadTargetWorkbooks()`。
- 新增模板铺量专用 sheet 名称读取方法：`.xlsx/.xlsm` 先调用 `GetXlsxSheetNames`，无结果再调用 `GetSheetNamesByNpoi`；`.xls` 直接调用 NPOI。

优点是改动最小，业务边界清楚，直接消除不必要的 UI 热路径。代价是模板切换后，目标 Excel 列表中可能暂时保留上一次加入的模板源项；用户展开目标 Excel 下拉框时会立即刷新为当前状态。当前目标 Excel 选择保持不变，这是预期行为。

### 方案 B：保留每次刷新，但缓存枚举结果和 sheet 列表

能够缩短重复切换，但需要处理 WPS 打开/关闭、文件修改时间和缓存失效，仍会让模板切换承担与目标工作簿无关的职责。缓存失效不完整时还可能显示陈旧列表，因此不采用。

### 方案 C：把刷新放到后台线程

界面可能更流畅，但涉及 COM 线程模型、控件跨线程更新和窗口关闭时的任务生命周期，风险明显高于本次需求，因此不采用。

## 组件与数据流

### 模板切换

```text
用户选择模板
  -> ComboBox 更新 SelectedItem
  -> 预览时按模板名 LoadFillTemplate
  -> 保持当前目标 Excel 和目标 sheet
```

模板切换不再调用工作簿枚举，也不读取模板源工作簿。

### 目标 Excel 刷新

```text
窗口首次打开 / 用户展开“目标 Excel”
  -> TryListOpenSpreadsheetWorkbooks
  -> AddTemplateSourceWorkbook
       -> xlsx/xlsm: GetXlsxSheetNames
       -> 失败回退 GetSheetNamesByNpoi
       -> xls: GetSheetNamesByNpoi
  -> 保留已有目标工作簿选择并刷新目标 sheet
```

## 兼容与异常处理

- 快速 sheet 读取返回空列表或异常时自动回退 NPOI，不改变错误容忍行为。
- `.xls` 不尝试 ZIP/XML 读取。
- 切换模板后不自动改变目标 Excel；模板关系和目标 Excel 本来就是两个独立状态。
- 用户打开目标 Excel 下拉框时仍会枚举当前 Excel/WPS，因此新开或已关闭的工作簿仍能及时反映。
- 删除或新建模板后，模板列表照常更新；目标工作簿列表在下次展开时更新。

## 测试

1. 扩展 `Test-TemplateFillNameMatch.ps1`：构造面板后切换两个临时模板项，验证 `targetWorkbookReloadCount` 不增加。
2. 使用临时 `.xlsx` 和 `.xls` 夹具反射调用模板铺量 sheet 名称读取方法，验证 sheet 名称正确、两种格式均兼容。
3. 编译当前 14 个 C# 源文件到工作区 `obj`，设置 `RECO_EXPAND_DLL` 后运行模板铺量完整回归。
4. 运行表头排序和自动绑定回归，防止影响相邻功能。
5. 对 4.6 MB“路基”源文件比较 `GetXlsxSheetNames` 与 NPOI：结果 sheet 数和顺序一致，并记录耗时。
6. 软件关闭后从当前确认提交生成干净源码 DLL，更新 `bin`、同事包和 SHA256 清单，再按统一部署规则同步三个运行目录。

## 完成标准

- 切换模板不再调用 `ReloadTargetWorkbooks()`。
- 当前目标 Excel 和目标 sheet 在模板切换后保持不变。
- 目标 Excel 下拉展开仍会刷新打开的 Excel/WPS。
- `.xlsx/.xlsm` sheet 列表使用快速路径并保留 NPOI 回退；`.xls` 行为不变。
- 全部相关回归通过，4.6 MB 文件快速读取结果与 NPOI 一致。
- 只修改模板铺量窗口、测试、设计/计划文档和对应构建产物。
