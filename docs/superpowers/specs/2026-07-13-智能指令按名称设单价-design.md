# 智能指令按定额名称设置单价设计

## 1. 目标

给“智能指令助手”增加按定额名称设置绝对单价的能力。用户可用自然语言或固定句式指定名称和单价，助手先展示受影响行，用户确认后再修改。

本功能只允许修改定额编号严格等于 `ZLF`、`SH`、`SQ`、`SF`、`LF` 的行，不扩展到普通定额或其他辅助代码。

## 2. 用户指令

支持自然语言，例如：

```text
把定额名称为设备购置费的单价设为 1200
```

同时提供可稳定解析的固定句式：

```text
设单价 名称=设备购置费 1200
```

多组修改继续使用现有英文分号链式语法：

```text
设单价 名称=设备购置费 1200 ; 设单价 名称=临时设施费 800
```

固定句式沿用现有范围参数，可指定条目和单元；未指定时按现有智能指令规则作用于当前选中行或当前条目、当前单元。

完整固定句式为：

```text
设单价 [条目编号] 名称=<完整定额名称> <单价> [单元=<单元名称或所有>]
```

解析时，`名称=` 后到末尾单价前的全部文本作为完整名称，因此名称中可以包含空格。

## 3. 匹配与范围规则

1. 名称匹配字段为 `定额输入.工程或费用项目名称`。
2. 输入名称去除首尾空格后，与数据库名称去除首尾空格后的结果进行完全匹配；不做包含、分词、模糊或近似匹配。
3. 在本次指令的条目、选中行和单元范围内，所有名称完全相同的行都进入候选集合。
4. 候选行的定额编号必须严格等于以下五个代码之一：`ZLF`、`SH`、`SQ`、`SF`、`LF`。
5. 普通定额、`TLF` 及其他辅助代码即使名称完全相同也不得修改，并在预览警告中说明跳过数量。
6. 未找到名称完全匹配且代码允许的行时，不生成更新计划，并明确提示“未找到可修改的目标”。

## 4. 命令模型与解析

新增独立命令类型 `set_unit_price_by_name`，避免与现有“单价乘除系数”命令混用。

命令包含：

- `items`：条目范围，沿用现有选中行、当前条目和条目编号解析规则。
- `include_children`：是否包含子条目，沿用现有规则。
- `units`：单元范围，未指定时为当前单元。
- `quota_name`：需要完全匹配的定额名称。
- `value`：要设置的绝对单价。

确定性解析器识别 `设单价` 固定句式；AI 解析请求同步增加该命令结构、限制规则和示例。命令结构校验要求名称非空、单价为可转换的数值。

## 5. 计划生成与执行

目标行查询复用现有 `ResolveAgentTargetRows` 的条目、选中行和单元定位能力，并让目标行模型读取名称字段。

对每条允许修改的目标行：

1. 将输入单价按三位小数四舍五入，使用 `MidpointRounding.AwayFromZero`。
2. 更新 `定额输入.单价`。
3. 使用新单价乘当前工程数量计算合价；单价保留三位小数，合价沿用现有规则保留两位小数。
4. 预览中显示单元、条目、定额编号、定额名称、旧单价和三位小数的新单价。
5. 执行时复用现有字段更新、事务、主程序表格同步和撤销记录机制。

该命令不修改定额编号、工程数量、定额调整或材料价格方案，也不直接写入定额库或材料单价库。

## 6. 错误与提示

- 名称为空：拒绝解析并显示固定句式用法。
- 单价不是有效数值：拒绝解析，不生成预览。
- 没有当前条目或单元上下文：沿用现有范围解析错误提示。
- 找到同名行但代码均不允许：不修改，提示仅支持 `ZLF、SH、SQ、SF、LF`。
- 同时存在允许和不允许的同名行：只预览允许行，并警告其余行已跳过。
- 从预览到确认期间目标数据发生变化：沿用现有并发校验，要求重新发起指令。

## 7. 帮助说明

智能指令帮助表新增“按名称设单价”条目，展示自然语言、固定句式、三位小数规则、完全匹配规则和允许代码范围。现有“改单价”帮助继续表示按系数乘除，不改变原行为。

## 8. 验证标准

1. `设单价 名称=设备购置费 1200` 能生成预览，新单价显示为 `1200.000`。
2. 自然语言“把定额名称为设备购置费的单价设为 1200.1234”能解析为新命令，并预览为 `1200.123`。
3. 名称只有完全相同时才命中；前后空格不影响匹配，名称子串不命中。
4. 当前范围内多条同名、允许代码的行全部进入同一次预览。
5. `ZLF`、`SH`、`SQ`、`SF`、`LF` 均可修改。
6. 普通定额、`TLF` 和其他辅助代码不能被修改。
7. 单价和合价执行后正确写入，主程序当前表格同步显示。
8. 撤销能恢复修改前的单价和合价。
9. 现有“单价 *系数”和其他智能指令解析、预览及执行行为不回归。

## 9. 不在本次范围内

- 模糊名称匹配或候选名称选择。
- 修改材料单价库、台班单价库或价格方案。
- 放开 `TLF`、普通定额或其他代码。
- 批量导入名称与价格表。
- 改变现有按系数乘除单价的命令语义。
