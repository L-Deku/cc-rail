# 建 reco_plugin 账号并生成配置文件：逐步操作（小白版）

不需要 SSMS，不需要 sa 密码。你电脑上已经存着管理员账号 `reco`，它在两台服务器上都是最高权限，脚本会用它替你建号。

## 唯一要做的事：双击一个文件，输两遍密码

1. 先想好一个新密码给新账号 `reco_plugin` 用。要求：只用英文字母和数字，至少 12 位，不要空格、中文、标点。例如 `RecoPlugin2026abc`（请自己另想一个），记在安全的地方。
2. 打开文件夹 `D:\AI文件\自动预算\tools\RecoCredential\`。
3. 双击 `一键建立插件SQL账号.cmd`。会弹出一个黑色窗口。
4. 窗口提示"请为新账号 reco_plugin 设置密码"，输入密码（屏幕上只显示星号或什么都不显示，都是正常的），回车。
5. 提示"请再输入一次确认"，再输一遍，回车。
6. 等它跑完。两台服务器上一共有近 4000 个项目库要逐个授权，整个过程大约 10 到 20 分钟，窗口里每 50 个库会报一次进度，**期间不要关窗口**。正常会看到：
   - `==== 学习库服务器(.213)` 下面"登录名 reco_plugin 已就绪"、"已授权 RecoLearning…"、多行"进度 …/627"，最后 `PASS：学习库服务器(.213) 全部 … 个项目库已授权只读`
   - `==== 业务库服务器(.13)` 同样，进度到 …/3200 左右，最后 `PASS：业务库服务器(.13) 全部 … 个项目库已授权只读`
   - `==== 生成插件 SQL 配置文件` 下面三行 `PASS：…权限核对通过`，然后 `PASS：插件 SQL 配置文件已生成：…RecoPluginSql.json`
   - 最后一行 `全部完成。`
7. 按任意键关闭窗口，回到聊天里说"配置文件已生成"。

## 如果出错

- **"两次输入不一致"或"密码只能用英文字母和数字"**：按提示重输即可，脚本会一直等你。
- **"不是 sysadmin"**：说明本机存的管理员账号权限变了，把整段红字发给 Claude。
- **红字里有 "Login failed" 或 "18456"**：本机存的 `reco` 账号密码和服务器不一致，把整段红字发给 Claude。
- **"以下库还没有 reco_plugin 用户：xxx"**：某个库授权失败，把整段红字发给 Claude。
- 其他任何红字：截图或复制整段发给 Claude。脚本可以反复运行，不会因为重复执行出问题。

## 发给同事：让同事的软件也能用

发布包在 `D:\AI文件\自动预算\release\同事插件分层发布\`，把整个文件夹拷到 U 盘或共享盘带给同事。同事电脑必须在公司内网（能访问 192.168.2.213 和 192.168.2.13）。

**同事第一次装插件**（电脑上还没有 RecoPluginLoader.dll）：
1. 关闭计价软件（ReJJGSNet2024 和 RejjNet2020 都关）。
2. 找到同事电脑上计价软件的安装目录（就是有 `ReJJGSNet2024.exe` 或 `RejjNet2020.exe` 的那个文件夹）。
3. 把 `00-首次安装公共包` 里的所有文件复制进去。
4. 把 `01-综合扩展功能包` 里的所有文件复制进去。
5. 把 `02-推荐定额功能包-首次安装` 里的所有文件（含 RecoQuotaData 文件夹）复制进去。
6. 在软件目录里双击 `安装插件.cmd`，看到 "Plugin installation completed." 即可。
7. 打开软件正常使用。绑定和推荐会自动写进学习库，不需要输任何密码。

**同事已经装过旧版插件**（只是更新）：
1. 关闭计价软件。
2. 把 `90-后续更新文件\公共组件更新`、`综合扩展更新`、`推荐定额更新` 三个文件夹里的文件复制到软件目录覆盖。其中 `RecoPluginSql.json` 是新增的，一定要复制。
3. 打开软件即可。不要复制 RecoQuotaData，以免覆盖同事自己的模板。

**怎么确认同事那边好了**：让同事随便做一次定额绑定，然后告诉 Claude 绑定的工程量名称，Claude 会到学习库里查这条流水。如果同事电脑软件目录里的 `RecoExpandPanel.log` 出现 "Login failed" 或 "拒绝"，把那几行发给 Claude。

## 只补固定库、不逐库（约 1 分钟）

如果 Claude 让你"补一下固定库授权"，双击同文件夹里的 `补授权固定库-不逐库.cmd`，输两遍密码即可。它只处理 RecoLearning、RecoData2024、RecoData2020、model 这几个库并重新生成配置文件，不再逐个项目库跑。

## 以后换密码怎么办

再双击一次 `一键建立插件SQL账号.cmd`，输入新密码。它会把两台服务器上的 `reco_plugin` 密码改成新的，并重新生成 `RecoPluginSql.json`。然后把新文件发给同事，覆盖软件根目录里的同名文件（覆盖前关软件）。
