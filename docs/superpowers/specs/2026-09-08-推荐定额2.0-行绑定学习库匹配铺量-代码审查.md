## 2. P1

### 2.1 ★ 批量绑定：失败行不占位，后续定额静默绑到上一行工程量
- `tools/RecoExpandPanel/ExcelLinkFeature.cs:1392-1411`：`address = startRef.Row + bound`，`bound` 只在 `TryCreateQuotaLink` 成功时递增，失败行 `continue` 且 `error` 丢弃。
- 触发：选 [Q1, Q2(无定额序号), Q3] 从 E4 起 → Q1→E4、Q2 跳过、Q3→E5（应为 E6）。学习库同时写入错误配对；提示"已批量绑定 2 条"无告警。
- 修法：行偏移用行在 `rows` 中的序号；收集失败行原因在结果框列出。补反射用例。

### 2.2 ★ 绑定存储非原子写，损坏后静默退空库，下次保存覆盖全部历史绑定
- `ExcelLinkFeature.cs:5802-5811` `SaveStore` 直接 `File.Create` 序列化；`:5778-5799` `LoadStore` 反序列化失败仅记日志并返回 `new ExcelLinkStore()`。
- 触发：序列化中途崩溃/磁盘满 → XML 截断 → 任何绑定操作加载得空库 → 保存时用只含新绑定的库覆盖。面板 `Reload`（`:7440`）因 `RefreshStoredQuantityNames>0` 也会回写。
- 修法：临时文件 + `File.Replace`（`LearningDbFeature.cs:699` 已有 `WriteAllLinesAtomic` 模式）；加载失败时把损坏文件改名备份并向调用方返回失败，禁止在加载失败状态下保存。

### 2.3 学习库：一个不合规组导致整批永久失败，合规组一条不写
- `LearningDbFeature.cs:88-136` `validGroups` 未按 `IsLearningFeedbackGroupRecommendable` 过滤；`:424-428` → `HasUnsupportedLearningDbMethod(:650-672)` 只要 `invalidEvidenceCount>0` 即 `PermanentFailure`。
- 触发：`excel-bind-batch` 几十行里有一行 SF 绑在非"设备购置费"条目或 SH/ZLF 缺名称/单位 → 全批学习丢失，UI 只见日志。
- 修法：剔除不可推荐组单独记日志；只在全部无效时返回永久失败。

### 2.4 Excel 行签名与 SQL 侧签名归一口径不一致，含尾部单位的名称精确层命不中
- 读侧行键 `SmartFillFeature.cs:1937` `NormalizeForSignature(row.RawName)` 不剥单位；SQL 侧 `:580-590` 经 `QuantityAlias` → `BuildSmartQuantitySignature` 剥 `" 单位"` 尾缀；公式操作数 `:1431/1438` 同样不剥而快照 `:~866` 剥过；写侧 `LearningDbFeature.cs:1156`、`ExcelLinkFeature.cs:2639` 写未剥离签名。
- 触发：名称单元格自带单位（`混凝土 m3`）→ 刚绑定的关系下次预览精确/同名层命不中，退化为模糊候选。
- 修法：以 `BuildSmartQuantitySignature(raw, unit)` 为唯一 canonical，写侧、读侧行键、`Rebuild-Aggregates.ps1`（见 3.6）三处统一；补"含 ` m3` 尾缀绑定后可精确命中"回归。

### 2.5 ★ 括号单位里的数字击穿数字规格惩罚
- `TemplateFillNameMatch.cs:52-68` `ExtractMatchNumbers`、`:118`（数字集不相交才 /3）、`:37-50` `NormalizeQuantityMatchName` 只剥"空格+单位"后缀。
- ★ 复现（面板 DLL 反射）：

  | 对 | 分 | 说明 |
  | --- | --- | --- |
  | `C30混凝土(m3)` vs `C25混凝土(m3)` | **57** | ≥ `NameMatchMinScore` 55，会被自动认领 |
  | `C30混凝土` vs `C25混凝土` | 13 | 去掉括号单位后惩罚正常 |
  | `DN100PE管(100m)` vs `DN150PE管(100m)` | **90** | `100m` 的数字与对方相交 |

- 修法：`NormalizeQuantityMatchName` 同时剥 `（单位）`/`(单位)` 尾缀（用 `LooksLikeExcelLinkUnit` 判定）；`ExtractMatchNumbers` 跳过紧贴单位字母的数字；与 `SmartFillFeature.cs:1377-1382` "数字序列完全相等"策略二选一统一。补样例。

### 2.6 ★ 推荐定额「勾选选中行」绕过确认链，随后整批写入被拒且不指名
- `TemplateFillPanel.cs:614-636` `SetSelectedSmartGroupsChecked` 直接 `item.Selected = value` 并在 `updatingNameQuotaCell=true` 下写单元格 → 不走 `ConfirmExactNameFromCheck`（`:1598-1641`）：`NeedExactNameConfirmation` 不清、软状态不消、红/黄底不退。
